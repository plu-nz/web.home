# Source

- [index.tsx](index.tsx) renders the PLUNZ landing page and current app catalog.
- [locale.ts](locale.ts) contains English, Portuguese, and Spanish copy and browser-language detection.
- [locale-preference.ts](locale-preference.ts) reads and writes the shared `plu.nz` language cookie and migrates an earlier local choice.
- [style.css](style.css) defines visual tokens, responsive layout, and interaction states.
- [worker.ts](worker.ts) redirects the apex host to `www` and serves static assets.
