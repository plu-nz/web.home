# Public assets

- [favicon.svg](favicon.svg) is the square PLUNZ mark, using the exact Darkppuccin arrow colors.
- [icon-maskable.svg](icon-maskable.svg) is the source for the inset maskable icon.
- `icon-192.png`, `icon-512.png`, and `icon-maskable-512.png` are raster exports for installation surfaces.
- [site.webmanifest](site.webmanifest) declares the app name, colors, and installable icons.

Regenerate PNGs with `rsvg-convert` when editing the SVG sources. Return to the [repository overview](../README.md).
